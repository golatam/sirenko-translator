# Translator — popup-переводчик для macOS по двойному Cmd+C

Выделяешь текст в любом приложении, дважды жмёшь `Cmd+C` — над курсором появляется окно с AI-переводом. Без окон, без вкладок, без переключений между приложениями.

[English version](README.md)

## Возможности

- **Двойной `Cmd+C`** — работает в любом приложении, без прав Accessibility
- **Popup у курсора** — появляется там, куда смотришь; следует за тобой по Spaces и fullscreen-приложениям
- **Потоковый вывод** — перевод появляется слово за словом
- **Три бэкенда перевода:**
  - **Claude API** — лучшее качество (API-ключ или повторное использование входа Claude Code)
  - **ChatGPT** — через подписку ChatGPT Plus и вход Codex CLI
  - **Локальный (офлайн)** — модели OPUS-MT на устройстве: бесплатно, приватно, без интернета
- **Replace** — одним кликом вставляет перевод обратно поверх выделенного текста
- **Настраиваемые глобальные хоткеи** — мгновенный перевод буфера в конкретный язык
- **Выбор модели** — Haiku для скорости или Sonnet для качества, прямо в настройках
- **Автообновление** — приложение само обновляется из GitHub Releases

## Установка

1. Скачай свежий `Translator.app` из [Releases](https://github.com/golatam/sirenko-translator/releases/latest).
2. Перемести в `/Applications`.
3. Приложение не подписано сертификатом Apple, поэтому при первом запуске macOS будет ругаться. Либо правый клик → **Open** → **Open**, либо:

   ```bash
   xattr -dr com.apple.quarantine /Applications/Translator.app
   ```

4. Запусти — в строке меню появится иконка **T**.

## Как пользоваться

1. Выделить текст в любом приложении.
2. Нажать `Cmd+C` дважды подряд (в пределах ~1 секунды).
3. Появится popup: язык-источник определяется сам, перевод стримится в окно.
4. Целевой язык можно сменить прямо в popup — последний выбор запоминается.
5. **Copy** кладёт перевод в буфер; **Replace** вставляет его поверх исходного выделения.

Глобальные хоткеи переводят текущий буфер в фиксированный язык. По умолчанию (меняются в Settings → Global Shortcuts):

| Хоткей | Язык |
|---|---|
| `Ctrl+Cmd+E` | английский |
| `Ctrl+Cmd+R` | русский |
| `Ctrl+Cmd+S` | испанский |

## Бэкенды перевода

Выбираются в **Settings → Translation Mode**.

| Режим | Что использует | Когда полезно |
|---|---|---|
| **Cloud → Claude** | Claude API: личный API-ключ с [platform.claude.com](https://platform.claude.com) или вход [Claude Code](https://claude.com/claude-code). | Лучшее качество. |
| **Cloud → ChatGPT** | Подписка ChatGPT Plus через вход [Codex CLI](https://github.com/openai/codex) (`codex login`). | Уже есть Plus, не хочется отдельного ключа. |
| **Local** | [OPUS-MT](https://github.com/Helsinki-NLP/Opus-MT) через `@xenova/transformers` в worker thread. Разовая загрузка ~50 МБ на языковую пару. | Офлайн, бесплатно, приватно. Качество чуть ниже. |

> **Про повторное использование подписок.** Реюз входа Claude Code / Codex CLI — неофициальный механизм, Anthropic и OpenAI его не поддерживают, и он может перестать работать в любой момент. Официальный путь — API-ключ Claude или локальный режим.

## Приватность

- В облачном режиме переводимый текст уходит в Anthropic или OpenAI. Больше ничего с машины не уходит.
- В локальном режиме наружу не уходит вообще ничего.
- Ни аналитики, ни телеметрии, ни аккаунтов.

## Сборка из исходников

Нужны Node.js 18+ и macOS на Apple Silicon.

```bash
git clone https://github.com/golatam/sirenko-translator.git
cd sirenko-translator
npm install
npm start          # запуск в dev-режиме
npm run dist       # собрать .app → dist/mac-arm64/ (Apple Silicon)
npm run dist:x64   # сборка под Intel
npm run deploy     # собрать + поставить в /Applications
```

Документация для мейнтейнера (процесс релиза, устройство автообновления, обходной путь с ASAR) — в [docs/RELEASING.md](docs/RELEASING.md).
